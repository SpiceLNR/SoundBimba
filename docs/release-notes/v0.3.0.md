## SoundBimba 0.3.0 — куда играет сама программа

### «Оригинал звука»
В узле «Звук приложения» теперь можно выбрать, куда играет **сама программа**, а не только её копия в SoundBimba:
- **Как обычно** — ничего не меняется.
- **На устройство** — например, игра только в одни наушники. Копия в SoundBimba остаётся.
- **Только через SoundBimba** — оригинал уходит на устройство, которое вы не слушаете (например, звук на монитор), и программу слышно только так, как она проходит через вашу схему: с компрессором, морфером, громкостью.

Это та же настройка, что «Параметры → Звук → Громкость приложений и устройства». SoundBimba показывает, что изменено, и **сама возвращает как было** — когда вы выбираете «Как обычно», удаляете узел, выключаете звук или закрываете программу (после аварийного закрытия — при следующем запуске). Windows меняет это только у программы, которая уже издаёт звук; иногда, чтобы звук перешёл, программу или её воспроизведение нужно перезапустить.

### Прочее
- «Фрутигер аэро»: кнопка «Звук включён» — стеклянная, надпись и лампочка светятся, как провода.
- В релиз больше не попадают старые установщики (в 0.2.0 по ошибке был лишний файл 0.1.0).

### Установка
Сборка **без цифровой подписи**: Windows может предупредить — «Подробнее» → «Выполнить в любом случае». Подлинность файла можно сверить с `SHA256SUMS.txt` (`Get-FileHash .\SoundBimba_0.3.0_x64-setup.exe`). Ставится поверх прежней версии, ваши схемы и настройки сохраняются.

## SoundBimba 0.3.0 — where the app itself plays

### "Original sound"
The "App sound" node now lets you choose where **the app itself** plays, not only its copy in SoundBimba:
- **As usual** — nothing changes.
- **To a device** — e.g. a game only in one pair of headphones. The copy in SoundBimba stays.
- **Only through SoundBimba** — the original goes to a device you don't listen to (e.g. monitor audio), and you hear the app only the way it passes through your map: with the compressor, morpher, volume.

It's the same setting as "Settings → Sound → App volume and device preferences". SoundBimba shows what it changed and **restores it by itself** — when you choose "As usual", delete the node, turn sound off or close the program (after a crash — on the next start). Windows changes this only for an app that is already playing sound; sometimes the app or its playback needs a restart for the sound to move.

### Other
- Frutiger Aero: the "Sound on" button is glass, its label and lamp glow like the wires.
- Old installers no longer end up in a release (0.2.0 had a stray 0.1.0 file by mistake).

### Installation
This build is **not digitally signed**: Windows may warn — "More info" → "Run anyway". Check the file against `SHA256SUMS.txt` (`Get-FileHash .\SoundBimba_0.3.0_x64-setup.exe`). Installs over the previous version; your setups and settings are kept.
