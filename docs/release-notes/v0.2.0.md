## SoundBimba 0.2.0 — эффекты и новые темы

### Новые узлы
- **Компрессор** — выравнивает громкость: тихий голос громче, громкое не хрипит. Наборы «Голос», «Громче тихое», «Сильно» (на голосе автора — громче на 10–16 дБ), шкала «сжимает сейчас». Клавиша 5.
- **Морфер голоса** — семь голосов: Обычный, Монстр, Бурундук, Робот, Рация, Пещера, Пришелец; ползунки высоты, дрожания, «робота», «рации» и эха. Кнопки голосов есть и в простом режиме. Клавиша 6.
- **Шумоподавление** — нейросеть RNNoise прямо на компьютере (без интернета): убирает гул, вентилятор, клавиатуру. Индикатор «слышу голос». Задержка около 20 мс. Клавиша 7.

### Новые шаблоны
- «Чистый голос» — шумоподавление → компрессор → виртуальный микрофон.
- «Изменённый голос» — микрофон → морфер → виртуальный микрофон.

### Темы
Теперь их шесть: **Бимба**, **Метро**, **Детская** (флеш-игра нулевых, Comic Sans), **Нео-нуар** (неон и мерцание), **Инженерская** (печатная плата), **Фрутигер аэро** (стекло и пузыри в духе Windows 7). Анимации выключаются, если в Windows выключены эффекты анимации.

### Прочее
- Клавиши добавления узлов — цифры 1–9 по порядку списка «Добавить узел» (свои назначения сохраняются).
- Исправлено: в некоторых темах выпадающие меню открывались под картой.

### Известное
- Наушники **Virtual Desktop Audio** (звук в VR-шлем) щёлкают пачками даже без SoundBimba — это само устройство. Через VB-CABLE и обычные наушники звук чистый.

### Установка
Сборка **без цифровой подписи**: Windows может предупредить — «Подробнее» → «Выполнить в любом случае». Подлинность файла можно сверить с `SHA256SUMS.txt` (`Get-FileHash .\SoundBimba_0.2.0_x64-setup.exe`). Ставится поверх 0.1.0, ваши схемы и настройки сохраняются.

## SoundBimba 0.2.0 — effects and new themes

### New nodes
- **Compressor** — evens out loudness: a quiet voice gets louder, loud parts don't distort. Presets Voice, Lift quiet parts, Strong (+10–16 dB on the author's voice), live reduction meter. Key 5.
- **Voice morpher** — seven voices: Normal, Monster, Chipmunk, Robot, Radio, Cave, Alien; sliders for pitch, wobble, robot, radio and echo. Voice buttons in simple mode too. Key 6.
- **Noise suppression** — the RNNoise neural network running locally (offline): removes hum, fans, keyboard. "Voice detected" indicator. About 20 ms of latency. Key 7.

### New templates
- "Clean voice" — noise suppression → compressor → virtual microphone.
- "Changed voice" — microphone → morpher → virtual microphone.

### Themes
Six now: **Bimba**, **Metro**, **Kids** (2000s Flash game, Comic Sans), **Neo-noir** (neon and flicker), **Engineer** (printed circuit board), **Frutiger Aero** (Windows 7 style glass and bubbles). Animations are off when Windows animation effects are off.

### Other
- Add-node keys are digits 1–9 in the order of the "Add node" list (your own bindings are kept).
- Fixed: in some themes dropdown menus opened below the map.

### Known issues
- **Virtual Desktop Audio** headphones (sound to a VR headset) click in bursts even without SoundBimba — it's the device itself. Through VB-CABLE and regular headphones the sound is clean.

### Installation
This build is **not digitally signed**: Windows may warn — "More info" → "Run anyway". Check the file against `SHA256SUMS.txt` (`Get-FileHash .\SoundBimba_0.2.0_x64-setup.exe`). Installs over 0.1.0; your setups and settings are kept.
