# SoundBimba

**Русский** · [English](README.en.md) · [Українська](README.uk.md)

SoundBimba — бесплатная программа для Windows, в которой звук собирается как схема: источники
слева, выходы справа, между ними провода. Без интернета, без рекламы и телеметрии.

- **Звук программ** — копия звука игры, плеера или браузера; у вас он продолжает играть как раньше.
- **Микрофон**, **кнопки-звуки** (как саундпад), **громкость** на любом проводе.
- **Выходы:** наушники и **виртуальный микрофон** — его выбирают в Discord, OBS или игре.
- **Кнопочная панель** — отдельное окно поверх игр; **простой режим** без карты.
- **Готовые схемы** одним щелчком и мастер виртуального кабеля для новичков. Свои схемы можно
  сохранять как шаблоны — файлы `.bmb`, которыми удобно делиться (открываются двойным щелчком).
- Языки: русский, английский, украинский. Темы «Бимба» и «Метро».
- Горячие клавиши работают только в окне SoundBimba (не мешают играм) и переназначаются.

## Что нужно

- **Windows 11, 64 бит.** На Windows 10 программа не проверялась.
- Для виртуального микрофона — бесплатный **VB-CABLE** с официального сайта
  [vb-audio.com/Cable](https://vb-audio.com/Cable/). SoundBimba его не устанавливает и не
  содержит: кабель ставите вы, один раз. Внутри программы есть пошаговая инструкция
  («Проект → Виртуальный кабель…»).

## Установка

1. Скачайте `SoundBimba_…_x64-setup.exe` и `SHA256SUMS.txt` со страницы
   [Releases](https://github.com/SpiceLNR/SoundBimba/releases).
2. Проверьте, что файл не подменён (по желанию): в PowerShell выполните
   `Get-FileHash .\SoundBimba_0.2.0_x64-setup.exe` — число должно совпасть с `SHA256SUMS.txt`.
3. Запустите установщик. Права администратора не нужны. Интернет не нужен: движок окна
   (Microsoft WebView2) уже внутри установщика.

**Почему Windows предупреждает «Windows защитила ваш компьютер».** Пока у релизов нет цифровой
подписи (см. «Политика подписи»). Нажмите «Подробнее» → «Выполнить в любом случае». Если
сомневаетесь — сверьте SHA-256 (шаг 2) или соберите программу сами.

**Удаление:** «Параметры → Приложения → SoundBimba → Удалить». Ваши схемы и настройки лежат в
`%APPDATA%\SoundBimba\` — удалите эту папку, если они больше не нужны.

## Первые шаги

1. При первом запуске выберите «Взять готовую схему», например «Кнопки-звуки в Discord».
2. Щёлкните по узлу — справа появятся его настройки: какая программа, какое устройство, какой звук.
3. Включите звук кнопкой «Звук выключен» слева вверху.
4. В Discord (или OBS, игре) выберите микрофон **«CABLE Output»**.

Задержка до виртуального микрофона — около 90 мс, из них около 70 мс добавляет сам VB-CABLE.
Проверить у себя: «Проект → Виртуальный кабель… → Проверить связку».

Если что-то не работает — «Проект → Сохранить диагностику» и приложите zip к
[сообщению об ошибке](https://github.com/SpiceLNR/SoundBimba/issues). В нём журнал программы,
ваша схема и настройки, сведения о Windows и звуковых устройствах. Самих звуковых файлов там нет,
но пути к ним видны (в пути может быть имя пользователя Windows) — посмотрите zip перед отправкой.

## Политика подписи

Сейчас релизы **не подписаны**. Мы подали (или подадим) заявку на бесплатную подпись для
открытых проектов в SignPath Foundation. Когда её одобрят, установщики будут подписываться в
автосборке GitHub, а здесь появится запись об этом. Ключей и сертификатов в репозитории нет и не
будет. До тех пор у каждого релиза есть файл `SHA256SUMS.txt`, а сборка полностью открыта: её
шаги — в [.github/workflows/build.yml](.github/workflows/build.yml).

## Собрать самому

Нужны Rust (MSVC), Node.js 24, Visual Studio 2022 с компонентом C++ и Windows 11 SDK.
Команды выполняйте в PowerShell (не в Git Bash):

```powershell
cd app
npm ci
npx tauri build
```

Готовый установщик — `target\release\bundle\nsis\`. Тесты: `cargo test --workspace` и
`npm test` (в `app`). Устройство проекта описано в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
