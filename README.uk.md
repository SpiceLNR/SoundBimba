# SoundBimba

[Русский](README.md) · [English](README.en.md) · **Українська**

SoundBimba — безкоштовна програма для Windows, у якій звук збирається як схема: джерела
ліворуч, виходи праворуч, між ними дроти. Без інтернету, без реклами й телеметрії.

- **Звук програм** — копія звуку гри, плеєра чи браузера; у вас він і далі грає як раніше.
- **Мікрофон**, **кнопки-звуки** (як саундпад), **гучність** на будь-якому дроті.
- **Виходи:** навушники та **віртуальний мікрофон** — його вибирають у Discord, OBS чи грі.
- **Кнопкова панель** — окреме вікно поверх ігор; **простий режим** без карти.
- **Готові схеми** одним клацанням і майстер віртуального кабелю для новачків. Свої схеми можна
  зберігати як шаблони — файли `.bmb`, якими зручно ділитися (відкриваються подвійним клацанням).
- Мови: російська, англійська, українська. Теми «Бімба» та «Метро».
- Гарячі клавіші працюють лише у вікні SoundBimba (не заважають іграм) і перепризначаються.

## Що потрібно

- **Windows 11, 64 біт.** На Windows 10 програму не перевіряли.
- Для віртуального мікрофона — безкоштовний **VB-CABLE** з офіційного сайту
  [vb-audio.com/Cable](https://vb-audio.com/Cable/). SoundBimba його не встановлює і не містить:
  кабель ставите ви, один раз. У програмі є покрокова інструкція
  («Проєкт → Віртуальний кабель…»).

## Встановлення

1. Завантажте `SoundBimba_…_x64-setup.exe` і `SHA256SUMS.txt` зі сторінки
   [Releases](https://github.com/SpiceLNR/SoundBimba/releases).
2. Перевірте, що файл не підмінено (за бажанням): у PowerShell виконайте
   `Get-FileHash .\SoundBimba_0.3.0_x64-setup.exe` — число має збігтися з `SHA256SUMS.txt`.
3. Запустіть інсталятор. Права адміністратора не потрібні. Інтернет не потрібен: рушій вікна
   (Microsoft WebView2) уже всередині інсталятора.

**Чому Windows попереджає «Windows захистила ваш комп’ютер».** Поки що релізи не мають
цифрового підпису (див. «Політика підпису (Code signing policy)» нижче). Натисніть «Докладніше» → «Усе одно запустити».
Якщо сумніваєтеся — звірте SHA-256 (крок 2) або зберіть програму самі.

**Видалення:** «Параметри → Програми → SoundBimba → Видалити». Ваші схеми й налаштування лежать
у `%APPDATA%\SoundBimba\` — видаліть цю теку, якщо вони більше не потрібні.

## Перші кроки

1. Під час першого запуску виберіть «Взяти готову схему», наприклад «Кнопки-звуки в Discord».
2. Клацніть по вузлу — праворуч з’являться його налаштування: яка програма, який пристрій, який звук.
3. Увімкніть звук кнопкою «Звук вимкнено» ліворуч угорі.
4. У Discord (або OBS, грі) виберіть мікрофон **«CABLE Output»**.

Затримка до віртуального мікрофона — близько 90 мс, з них близько 70 мс додає сам VB-CABLE.
Перевірити в себе: «Проєкт → Віртуальний кабель… → Перевірити зв’язок».

Якщо щось не працює — «Проєкт → Зберегти діагностику» і додайте zip до
[повідомлення про помилку](https://github.com/SpiceLNR/SoundBimba/issues). У ньому журнал
програми, ваша схема й налаштування, відомості про Windows і звукові пристрої. Самих звукових
файлів там немає, але шляхи до них видно (у шляху може бути ім’я користувача Windows) —
перегляньте zip перед надсиланням.

## Політика підпису (Code signing policy)

Зараз релізи **не підписані** — кожен має `SHA256SUMS.txt` для перевірки. Пізніше, коли в проєкту
з’являться користувачі, ми подамо заявку на безкоштовний підпис для відкритих проєктів у
[SignPath Foundation](https://signpath.org). Тоді інсталятори підписуватимуться в автозбірці GitHub
([.github/workflows/build.yml](.github/workflows/build.yml)), і кожен підпис вручну підтверджуватиме
відповідальний. Ключів і сертифікатів у репозиторії немає й не буде.

- Автори та перевіряльники змін (committers and reviewers): [SpiceLNR](https://github.com/SpiceLNR)
- Підтверджує підпис релізу (approvers): [SpiceLNR](https://github.com/SpiceLNR)

**Приватність.** Ця програма не передає жодних відомостей іншим мережевим системам, якщо про це
спеціально не попросить користувач або той, хто її встановлює чи запускає. SoundBimba взагалі не
виходить в інтернет; «Зберегти діагностику» записує файл лише туди, куди вкажете ви.

## Зібрати самому

Потрібні Rust (MSVC), Node.js 24, Visual Studio 2022 з компонентом C++ і Windows 11 SDK.
Команди виконуйте в PowerShell (не в Git Bash):

```powershell
cd app
npm ci
npx tauri build
```

Готовий інсталятор — у `target\release\bundle\nsis\`. Тести: `cargo test --workspace` і
`npm test` (в `app`). Будову проєкту описано в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) (російською).
